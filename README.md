# Repuyan-Maria-Fatima-A2-Drawing

Project Title: Daisy from Day to Night

Project is an interactive drawing of a flower that changes time of day from 'Daytime' to 'Nighttime'.

To use this project, follow the steps below:

if key == "Spacebar", is pressed, then the drawing will change from 'Daytime' to 'Nighttime' and vice versa

if key == "Spacebar",is not pressed, the drawing will remain in its current state of 'Daytime'.
